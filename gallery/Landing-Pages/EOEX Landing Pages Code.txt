EOEX JOB PROFILE LANDING PAGES: COMPREHENSIVE IMPLEMENTATION PLAN
1. Executive Summary
This document provides a complete blueprint for creating a suite of Single Page Application (SPA) landing pages for the EOEX ("The Elegance of Excellence") fashion industry job profiles. The goal is to build over 60 highly engaging, mobile-first, and multilingual landing pages that demonstrate EOEX's deep understanding of each role's challenges, as well as its ability to provide targeted solutions through masterclasses and services.


Each landing page leverages the detailed research from the EOEX FashionTech Research.pdf and EOEX Fashion Industry Job Profiles Compendium.pdf files. This document includes the project's research, architecture, design system, technical specifications, and a complete, documented implementation plan suitable for a VSCode Copilot prompt.
2. Project Research & Analysis
2.1 Frontier & Next-Generation SPA Architecture
Based on the requirement for a mobile-first, dynamic, and elegant SPA, the following technologies and architectural patterns have been researched and selected:


* Architecture Pattern: Component-Based Architecture. This allows for reusable and maintainable code, perfect for building 60+ similar landing pages from a set of core components. Each page will be a composition of these components.
* Core Technologies:
   * HTML5: Semantic and accessible markup.
   * CSS3: CSS Grid, Flexbox, and Custom Properties (CSS Variables) for layout and theming.
   * Vanilla JavaScript (ES6+): For DOM manipulation, event handling, API calls (for translations), and the video carousel logic.
   * WebGL: Achieved via Three.js for potential 3D interactive elements, such as subtle animations or interactive models, to enhance the "majestic" and "royal" feel. However, given the need for elegance and subtlety, a lightweight approach will be used, perhaps for a dynamic, animated hero background.
* SPA & Routing: A lightweight, custom router will be implemented in JavaScript to handle navigation between the different "sections" (which are effectively views) without full page reloads.
* Hosting: GitHub Pages, as requested.
* Content Management: All content will be stored in JavaScript objects, allowing for easy updates and serving as the basis for the multi-language functionality.
2.2 GitHub Repo & Hosting on GitHub Pages

2.3 Research on Similar Projects
* Fashion E-commerce Sites: Sites like Net-a-Porter, Farfetch, and SSENSE use clean, elegant typography, high-quality imagery, and subtle, smooth interactions to create a premium feel. Their mobile-first approach and seamless browsing experience are directly applicable.
* Masterclass & Educational Platforms: Platforms like MasterClass and Skillshare use strong, clear value propositions, high-production video, and compelling CTAs. Their approach to presenting expert-led courses and subject matter is informative.
* Product/Profile Landing Pages: Companies like Apple and Tesla use simple, narrative-driven layouts with bold typography and high-quality visuals to showcase products. This storytelling approach is powerful for connecting with an audience.


Key Takeaways:


* Simplicity & Elegance: A clean, uncluttered design with a focus on high-quality visuals and typography.
* Mobile-First: The design must prioritize the mobile experience, ensuring all content is easily accessible and readable on smaller screens.
* Storytelling: The landing page should not just list problems and solutions, but tell a story of the professional's journey, the challenges they face, and how EOEX can guide them to success.
* Clear CTAs: Every section must have a clear and compelling call to action, guiding the user toward the next step (e.g., "Attend the Masterclass").
3. Visual Design System: "The Elegance of Excellence"
The design system aims for a Royal, Majestic, and Professional aesthetic that aligns with the EOEX brand.


* Colour Palette:


   * Primary Background: Creamy Beige (#F5F2EB) to create a warm, premium, and inviting canvas.
   * Secondary Backgrounds: Off-white (#F8F6F3) for cards and content sections to add depth.
   * Primary Accent (Gold): #D4AF37 for highlights, CTAs, and decorative elements to signify value and quality.
   * Secondary Accent (Black): #1A1A1A (Subtle Black) for primary text, headings, and to provide strong contrast.
   * Text Color: #2C2C2C (Dark Charcoal) for body text to ensure readability on the beige/off-white backgrounds.
   * Separators: Elegant gold lines or subtle beige/black transitions.


* Typography:


   * Headings: A serif font like Playfair Display or Lora for a classic, elegant, and authoritative feel.
   * Body Text: A sans-serif font like Inter, Montserrat, or Lato for clean, modern readability across all devices.
   * Font Pairing: A combination of a serif for headings and a sans-serif for body text creates a sophisticated and balanced typographic hierarchy.


* UI Components:


   * Cards: Glossy, elegant cards with soft shadows, rounded corners (e.g., border-radius: 12px), and a subtle gradient background or border.
   * Collapsible Drawers: Clean, well-labeled accordions to present detailed content in a user-friendly and space-saving manner.
   * Buttons: Gold-filled or outlined buttons with subtle hover animations (e.g., slight scaling or a background color change).
   * Language Toggle: A subtle, icon-based toggle (e.g., a globe icon or language code abbreviations) in the header.
   * Video Carousel: A full-width, autoplaying, and muted carousel to create an immediate, immersive brand experience without being intrusive.

5. Functionality & Interaction Specifications
* Scroll Behavior: The SPA will utilize smooth scrolling to navigate between sections, enhancing the user experience.
* Collapsible Drawers: Clicking on a drawer's header will expand/contract its content, providing an efficient way to display detailed information without overwhelming the user.
* Dynamic Translation:
   * A language toggle will be present in the header.
   * All text content (headings, paragraphs, labels, CTAs) will be stored in a language JSON object.
   * When the user changes the language, the application will re-render all text on the page without a reload.
* Video Carousel:
   * JavaScript will manage a playlist of videos.
   * Videos will be played once, randomly, and on a continuous loop (the next video starts after the current one ends).
   * The carousel will be muted and have no user controls.
* WebGL Integration: A Three.js or p5.js script can be added to the hero section to create a subtle, dynamic background (e.g., floating geometric shapes or particles in gold and beige) that adds a layer of sophistication without interfering with readability.

8.3 js/app.js (Main Application)


// js/app.js


import { jobProfiles } from './data/jobProfiles.js';


import { translations, defaultLanguage } from './data/translations.js';


import { Router } from './router.js';


import { renderPage } from './pages/index.js';


class App {


    constructor() {


        this.currentLanguage = defaultLanguage;


        this.router = new Router();


        this.init();


    }


    init() {


        // Set up language toggle


        document.getElementById('language-toggle').addEventListener('click', () => {


            // Cycle through languages or show a dropdown


            const languages = Object.keys(translations);


            const currentIndex = languages.indexOf(this.currentLanguage);


            const nextIndex = (currentIndex + 1) % languages.length;


            this.currentLanguage = languages[nextIndex];


            this.translatePage();


        });


        // Router listener


        window.addEventListener('popstate', () => {


            this.loadPage(window.location.pathname);


        });


        // Load initial page


        this.loadPage(window.location.pathname);


    }


    loadPage(path) {


        const pageName = path.replace('/', '') || 'creative-director'; // Default


        const pageData = jobProfiles[pageName];


        if (pageData) {


            renderPage(pageData, this.currentLanguage);


        } else {


            // Handle 404


            document.getElementById('router-outlet').innerHTML = '<h1>Page not found</h1>';


        }


    }


    translatePage() {


        // Implementation to replace all text based on data-translate attributes


        const elements = document.querySelectorAll('[data-translate]');


        elements.forEach(el => {


            const key = el.getAttribute('data-translate');


            const translation = translations[this.currentLanguage][key] || key;


            if (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA') {


                el.placeholder = translation;


            } else {


                el.innerHTML = translation;


            }


        });


    }


}


// Initialize App


new App();


// Router (simplified)


export class Router {


    constructor() {


        this.routes = {};


    }


    addRoute(path, callback) {


        this.routes[path] = callback;


    }


    navigateTo(path) {


        window.history.pushState({}, '', path);


        // Call the page load function from app


    }


}
